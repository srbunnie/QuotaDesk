# Conectar o Figma

Não há nada a configurar: o card mostra se o serviço Figma Agent está no ar.

**Mostra:** se o serviço **Figma Agent** está operacional, degradado ou fora do ar.

## Como funciona

O QuotaDesk lê a página pública `status.figma.com` uma vez por hora. É o status global do serviço: não verifica os créditos nem as tarefas da sua conta, e não pede login.

## Se você não usa o Figma

Esconda o card em **Configurações › Ferramentas**, desmarcando o nome.
